# 🎬 Simple Video Player

## 📌 Description

Simple Video Player is a basic Android application developed using **Kotlin** in **Android Studio**. It uses Android's built-in **VideoView** and **MediaController** to play a preloaded video with basic playback controls.

The application automatically plays the video when launched and allows users to play, pause, and seek through the video using simple media controls.

## ✨ Features

- ▶️ Automatically plays the preloaded video.
- ⏯️ Play and pause video playback.
- ⏩ Seek forward or backward using the seek bar.
- 🎥 Uses Android's built-in VideoView and MediaController.
- 📱 Simple and user-friendly interface.
- 🔌 Works offline without an internet connection.

## 🛠️ Technologies Used

- **Language:** Kotlin
- **IDE:** Android Studio
- **UI:** XML
- **Components:** VideoView, MediaController
- **Platform:** Android

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/ashivarani/Simple-Video-Player.git
```

### 2. Open in Android Studio

- Open Android Studio.
- Select **Open** and choose the cloned project.
- Wait for Gradle synchronization.

### 3. Run the Application

- Connect an Android device or start an emulator.
- Click **Run** to launch the application.

## 📱 How to Use

1. Open the application.
2. The preloaded video starts playing automatically.
3. Tap the video to display media controls.
4. Use the controls to play, pause, or seek through the video.

## ⚙️ How It Works

The application uses **VideoView** to display and play a video stored in the application's resources.

**MediaController** provides basic playback controls, allowing users to pause, resume, and navigate through the video.
